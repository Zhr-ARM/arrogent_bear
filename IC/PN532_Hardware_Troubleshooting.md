# PN532硬件故障排除指南

## 🔍 **当前问题**
PN532模块始终返回0x00状态，说明模块没有正确响应。

## 🔧 **硬件检查步骤**

### **1. 电源检查**
- **VCC**: 确认3.3V电源供应
- **GND**: 确认地线连接
- **测量**: 用万用表测量VCC引脚电压应为3.3V

### **2. SPI连接检查**
确认以下连接正确：
- **SCK**: PB3 (SPI1_SCK) → PN532 SCK
- **MISO**: PB4 (SPI1_MISO) → PN532 MISO  
- **MOSI**: PB5 (SPI1_MOSI) → PN532 MOSI
- **CS**: PA4 (PN532_CS) → PN532 CS
- **RST**: PF0 (PN532_RST) → PN532 RST
- **IRQ**: PF1 (PN532_IRQ) → PN532 IRQ

### **3. SPI回环测试**
为了测试SPI通信是否正常，请：
1. **短接MOSI和MISO引脚**
2. 重新编译烧录程序
3. 查看串口输出中的SPI回环测试结果

**预期结果**:
```
Testing SPI loopback...
SPI Loopback: Send=0xAA, Receive=0xAA
```

**如果回环测试失败**:
- 检查SPI引脚连接
- 检查SPI配置
- 检查时钟频率

### **4. PN532模块检查**
- **模块型号**: 确认是PN532模块
- **工作电压**: 确认是3.3V版本
- **模块状态**: 检查模块是否有物理损坏
- **焊接**: 检查引脚焊接是否良好

### **5. 示波器检查**（如果有）
- **SCK信号**: 检查时钟信号是否正常
- **MOSI信号**: 检查数据发送信号
- **MISO信号**: 检查数据接收信号
- **CS信号**: 检查片选信号

## 📋 **测试步骤**

### **步骤1: 基本连接测试**
1. 检查所有连接
2. 确认电源供应
3. 重新编译烧录

### **步骤2: SPI回环测试**
1. 短接MOSI和MISO
2. 查看回环测试结果
3. 如果失败，检查SPI连接

### **步骤3: PN532模块测试**
1. 移除短接
2. 查看PN532状态
3. 如果仍为0x00，检查模块

## 🔍 **可能的问题**

### **硬件问题**
1. **连接错误**: SPI引脚连接错误
2. **电源问题**: 电压不正确或电源不稳定
3. **模块损坏**: PN532模块本身有问题
4. **焊接问题**: 引脚焊接不良

### **软件问题**
1. **SPI配置错误**: 时钟频率、模式等
2. **引脚配置错误**: GPIO配置不正确
3. **通信协议错误**: PN532通信协议不正确

## ✅ **解决方案**

### **如果SPI回环测试成功**
- 问题在于PN532模块或通信协议
- 检查模块连接和电源
- 尝试不同的通信协议

### **如果SPI回环测试失败**
- 问题在于SPI硬件连接
- 检查SPI引脚连接
- 检查SPI配置

### **如果所有测试都失败**
- 检查电源供应
- 检查模块是否损坏
- 尝试更换PN532模块
